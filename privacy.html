01

What It Does

RealTime Type types text you provide into a web page you choose, at a natural, human-like pace.

It only works on the tab you start it on, and only after you press Start in the extension’s popup. It does nothing in the background and nothing on any other page.

02

Data It Handles

While you use RealTime Type, the extension handles the following. None of it is sent anywhere.

  • The text you paste into the popup. This is the text it types for you.
  • The text box you are typing into. During a typing session the extension reads the contents and cursor position of the focused text box to check that text landed in the right place and to correct it if it didn’t. This is held in memory only while typing and is discarded afterward.
  • Mouse and key activity on the page. It tracks the mouse position so the “click to start” label can appear next to your cursor, notices clicks so it can pause when you click away, and counts key events received so it can tell when focus was lost. It does not record which keys you press.

RealTime Type does not collect your name, email, location, browsing history, passwords, payment details, or any other personal information.

03

Local Storage

The extension saves two things in your browser using chrome.storage.local:

  • The text you last pasted into the popup.
  • Your settings: typing speed and which options are switched on or off.

This lets the popup remember your choices next time. It is stored only on your device and is not synced to other devices or sent to any server.

04

Sharing

Nothing is shared. RealTime Type makes no network requests. It has no accounts, no analytics, no ads, and no tracking, and the developer has no access to anything you type or store.

Your data is never sold or transferred to third parties, never used for purposes unrelated to the extension’s single purpose, and never used to determine creditworthiness or for lending.

05

Permissions

RealTime Type asks for a small set of browser permissions, each for one reason:

  • Debugger. Sends real keyboard events so text is entered in editors that ignore script-generated keys, reads the focused text box to fix misplaced text, and keeps the page behaving as focused when its window is behind another one. While typing, Chrome shows a banner reading “RealTime Type started debugging this browser.” This is normal and goes away when typing finishes.
  • Scripting. Shows the “click to start” and “click to resume” label by your cursor and checks whether a text box is already focused.
  • Active tab and access to all sites. Lets RealTime Type type into whichever site you choose. It does nothing on a page until you press Start.
  • Storage. Saves your text and settings locally, as described above.
06

Limited Use

RealTime Type’s use of information is limited to providing its single purpose: typing the text you provide into the page you choose.

The use of information received through Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is not sold, not used or transferred for advertising, and not read by humans.

07

Security

Because your data never leaves your device, there is nothing to intercept in transit and nothing held on a server.

The extension reads the page only during an active typing session. When typing finishes or you stop it, the debugger connection is closed automatically.

08

Your Choices

  • Pause or stop at any time from the popup, or by clicking Cancel on Chrome’s debugging banner.
  • Clear your saved text by deleting it from the popup’s text box.
  • Remove everything by uninstalling the extension, which deletes all data it stored.
09

Policy Changes

If RealTime Type ever changes how it handles data, this policy and the extension’s Chrome Web Store disclosures will be updated first, and the “Last Updated” date at the top will change.
